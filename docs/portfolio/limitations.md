# Known Limitations

**当前 V1.1 实现：Portfolio Prototype / Mock / Manual Confirmation。**

- 单用户、本地运行；无权限系统、多用户协作或 CRM 集成。
- 浏览器 localStorage 保存数据；清理存储、换浏览器或端口会影响可见数据。它不是加密、备份或防篡改数据库。
- 没有接入真实 LLM；有限归因、量纲与场景规则不能处理任意自然语言。
- 结构化语义需要人工选择、确认。接受记录原文不代表命题已审核，更不代表事实已独立验证。
- 演练评分基于人工行为标注，存在标注主观性，不是通用 NLP 销售能力评估。
- AI Copilot 洞察读取当前缺口；行动为模板草稿。没有自主代理执行、联网搜证、自动报价或采购决策。
- 无生产级医疗数据或真实医院采购系统接入；没有医疗认证或临床有效性验证。
- 不应用于真实医疗决策、真实客户敏感数据或患者信息。Demo 不含真实客户、患者或医院内部数据。
- 多项目隔离在数据层有验证，界面尚不是成熟的多项目管理产品。
- 历史快照通过程序内深拷贝保护，不防止用户直接改本地 JSON；存储容量有限。
- Stage 反映代码中的条件集合，不是成交概率；不能推广成医院通用采购规则。界面技术字段和人工审核仍有学习成本。
- 当前回归 30/30 PASS；全历史集合的 29 项旧测试契约不兼容保留。不是“全部测试通过”或 CI 持续绿灯。
- 截图保留当前 UI 的低对比度侧栏文字、技术字段和人工表单，没有为作品集修改冻结样式或重新绘制界面。
- 既有浏览器测试有原开发机绝对路径依赖，需配置 Playwright 和 Chrome；核心 Node 测试无需这些浏览器依赖。

本轮只整理作品集，不把上述限制变成新的开发任务，也未执行部署。
